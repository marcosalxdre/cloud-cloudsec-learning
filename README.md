# Cloud SecOps Learning 

O objetivo deste repositório é documentar minha evolução e aprendizado em **Cloud Computing**, especialmente no que diz respeito à **administração e à segurança sob uma perspectiva defensiva**.

Nele, será possível acompanhar uma trilha de estudos desenvolvida para abordar desde os fundamentos até conceitos mais avançados nas áreas de **Cloud Computing, IAM, Redes de Computadores, Automação e uso de Inteligência Artificial aplicado ao contexto de nuvem**, sempre com foco em **administração, operação e segurança**.

A proposta é conectar os laboratórios e materiais desenvolvidos ao longo dessa jornada, partindo dos primeiros estudos sobre os fundamentos e avançando progressivamente para conteúdos e ambientes mais complexos.

Dessa forma, o repositório permite acompanhar não apenas a evolução do conhecimento adquirido, mas também como a infraestrutura e os laboratórios desenvolvidos se tornam gradualmente mais robustos à medida que o entendimento desses conceitos é aprofundado.

> **Nota:** Este repositório não tem como objetivo ser um guia definitivo sobre Cloud Computing ou Cloud Security, mas sim registrar, de forma prática e progressiva, meu processo de aprendizado, experimentação e desenvolvimento.
